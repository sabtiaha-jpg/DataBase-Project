# COMP333 Database Systems Project 


## 📌 Project Overview
This project is a database management system for **BioLine Company**, a medical and laboratory equipment supplier. The system is designed to improve data management, streamline operations, and support efficient querying of business data.

---

## 🏢 About the Company
BioLine Company is a supplier of medical and laboratory equipment serving medical centers and laboratories in Palestine.

- **Founder:** Abdelsalam Sarary  
- **Industry:** Medical and Laboratory Supplies  
- **Location:** Ramallah, Palestine  
- **Established:** April 5, 2016  
- **Website:** www.bioline.ps  

---

## ⚙️ Technologies Used
- Database: MySQL  
- Backend: Python  

---

## 🗄️ Features / Queries Implemented
The system supports multiple SQL queries including:

- Retrieve company, department, employee, and product data  
- Retrieve employees with work hours and salaries  
- Filter departments by employee count  
- Retrieve branch and supplier information  
- Product tracking (stock, categories, expiration dates)  
- Customer and employee management queries  
- Update operations for company and employee data  

---

## 🎯 Project Purpose
The goal of this project is to design and implement a structured relational database system that supports real-world business operations for BioLine Company.
